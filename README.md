### 🚀 About Me

I engineer high-scale **Discord bot infrastructure**, **real-time web dashboards**, **cybersecurity stress harnesses**, and **autonomous media pipelines**:

- 🤖 **15+ Production Systems Built**: From multi-tenant bot SaaS generators (`BotMaker`) to enterprise support suites with Drizzle ORM and React portals.
- 🛡️ **Cybersecurity & Protocol Auditing**: Author of `Seif Nuker`—an educational protocol stress-testing harness sustaining 250+ req/s to audit Discord rate-limit buckets (HTTP 429 recovery curves) and anti-raid heuristics.
- ⚡ **All Discord API Generations**: Deep engineering experience spanning **Discord.js (v12, v13, v14)**, **discord.py (all versions)**, **Disnake**, and raw **Gateway protocols (v6–v10)**.
- 🎥 **Headless Media Compositing**: Built GPU-accelerated video rendering pipelines using FFmpeg NVENC, HarfBuzz/FriBidi Arabic text shaping, and automated TikTok/Reels publishers.
